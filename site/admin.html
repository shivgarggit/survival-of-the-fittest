Roster admin

Survival of the Fittest

Add, edit or remove holding periods without touching code. Changes are written straight to roster.json in your repository and the site rebuilds itself.

1 · Connect

A fine-grained GitHub token with Contents: read and write on this repository only. It is stored in this browser and never sent anywhere except github.com.

Create one at github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens. Limit it to this single repository and grant only Contents write. Anyone with the token can write to the repo, so do not paste it on a shared computer.

2 · Holding periods

Click any row to edit it. Periods may not overlap, and weights must total 100%.

Edit period

Tap a ticker to add or remove it. Equal weight is applied automatically unless you set weights by hand.

3 · Publish

Writes roster.json to the repository and starts the rebuild. Takes three to six minutes.

Save without rebuilding if you want to make several edits first. The nightly run will pick them up regardless.

Writes to roster.json only. Prices, dividends and everything else are fetched by the scheduled job.
Changes are ordinary git commits, so every edit is reversible from the repository history.
